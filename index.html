Ogni clic crea una variante nuova, sincronizzata al BPM del progetto e inserita alla posizione della testina. Tutto viene sintetizzato in locale con Web Audio, senza server.

In attesa. BPM e tonalità vengono presi dal progetto.

Usa la demo pubblica di ACE-Step 1.5 su Hugging Face, che gira su GPU condivise: può esserci coda e c'è un limite di minuti al giorno. Con un token gratuito di Hugging Face (huggingface.co → Settings → Access Tokens, tipo "Read") il limite sale. Il token resta salvato solo in questo browser.

Serve ACE-Step 1.5 avviato sul tuo computer (python -m acestep.api_server, porta 8001) e la DAW aperta con python serve.py, che inoltra le richieste. Istruzioni complete nel README.

Ogni file diventa una nuova traccia alla posizione della testina. Puoi anche trascinare i file direttamente sull'arrangiamento.

Prossimi moduli in roadmap: separazione stem con Demucs, audio→MIDI con Basic Pitch, plugin Web Audio Modules.
